# 电子墓碑

一个使用 React + Vite 搭建的纪念网站基础版本，面向 PC 端展示，版心控制在约 1700px。

## 运行

请先确认本机已安装 Node.js。

```bash
npm install
npm run dev
```

也可以双击桌面快捷方式「启动电子墓碑网站」，或运行项目内的 `启动网站.bat`。

构建生产版本：

```bash
npm run build
```

## 页面模块

- 全屏首页 Hero：视频背景、大标题、导航栏、联系按钮
- 个人经历：人物图、介绍、联系方式、项目数据
- 精选项目：大卡片作品展示
- 个人优势：能力卡片
- 他人评价：评价卡片
- 底部联系方式：整屏收尾页
